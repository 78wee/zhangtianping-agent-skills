# Official Surge Sources

Use these as primary sources before uncertain or high-impact edits.

- Knowledge base: https://kb.nssurge.com/surge-knowledge-base
- Manual: https://manual.nssurge.com/
- Configuration file overview: https://manual.nssurge.com/overview/configuration.html
- Policy groups and included policies: https://manual.nssurge.com/policy-group/policy-including.html

Local CLI:

```bash
/Applications/Surge.app/Contents/Applications/surge-cli --help
```

Known available commands include `reload`, `switch-profile`, `dump active`, `dump request`, `dump rule`, `dump policy`, `dump dns`, `dump profile`, `dump event`, `environment`, `test-policy`, `test-group`, `kill`, and `flush dns`.
