# Kami Skill Integration

The Kami skill is maintained in `skills/shared/kami` so that compatible agent clients can use one shared implementation.

The integrated version includes document templates, reusable design references, validation scripts, and examples. Keep client-specific configuration outside the skill source and use the documented profile mechanism for optional branding values.

When updating the skill, review its license and upstream notices, run its repository checks, and keep generated examples synchronized with the templates.
